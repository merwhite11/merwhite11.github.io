In my first 2 weeks in AI Land, I realized my mental model of these terms was not solid. Before May, I considered myself a heavy user, but it was just using Claude Code in the terminal to ask questions against the code base. I had created a skill.md to automate merges to the documentation. I had searched logs in a table called 'spans' without giving much thought to what a span actually was. 

Then May came, I moved to AI Land and I'm quickly seeing that I have lots and lots of spans in my future. Traces full of them. 

Remember when your homework was to use your new vocab words in a sentence? Here's mine:

"The agent's call to the harness failed to load the hardcoded skill, but the traces showed it fell back to the LLM labeling call, and the GPU metrics confirmed a spike at the same time."

That would've really thrown me for a loop 3 hours ago, but here's what I've come to understand: 

**A GPU is like a CPU**, cores of processing power, but can compute massive, simultaneous, parallel math which honestly sounds like my worst nightmare. 

**An LLM is a model** that runs on many GCPUs. All LLMs are models. Not all models are LLMs. 

**A harness is code** that picks picks a model, formats a prompt on the fly by assembling fixed instructions with variable content (a skill, context from a database, or an LLM-generated hint). The point is that you can keep the harness code the same but have variable prompts. It calls the LLM once with a fixed goal, unlike an agent makes LLM calls in a loop. 

```
Agent (decides what to do) 
	└── calls Harness A (label this event) 
	└── calls Harness B (query the database) 
	└── calls Harness C (write a summary)
```

**Prompt is the full input** assembled and sent to an LLM. It can be a combination of hard-coded instructions, context from a database (like user input), and content generated by another LLM upstream.

**Skills are specific instructions** that can be added like sauce to the system prompt of an LLM. You can add as `SKILL.md` to your project so Claude (or your LLM) behave according to the task-specific context injected in every prompt. 

**Agents lack curiosity and flesh** and are not to be trusted. They are basically code loops (also my worst nightmare back in my leetcoding days) that follow prompts to call tools (harness, APIs, databases) and then call LLMs (Claude, Gemini) to check the result against the instructions, and repeat until the LLM finally deems it 'done'. 
```
while not done: 
	decide next action call a tool (harness, API, DB) 
	look at result 
	decide if done
```

**A span** is the log of one single timed operation triggered by an agent. 

**Traces are the logs** of all the tool calls, subagent calls, and intermediate results that the agent leaves in the wake of its blundering pursuits. 

A harness for every horse. Some use skills some use another LLM.
